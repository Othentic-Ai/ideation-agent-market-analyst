# Ideation Agent: Market Analyst

Market Size Researcher & TAM/SAM/SOM Financial Analyst for the Ideation Pipeline.

## Overview

This agent is part of the Ideation multi-agent pipeline. It performs:
1. **Market Research**: Gather market size data, growth rates, and dynamics
2. **Financial Analysis**: Calculate realistic TAM, SAM, and SOM estimates

## Installation

```bash
pip install -e .
```

## Usage

```bash
ideation-agent-market-analyst run --session-id <session-id>
```

## Part of Ideation Pipeline

This agent is orchestrated by the [ideation-orchestrator](https://github.com/Othentic-Ai/ideation-orchestrator).
